The map on the right works without any key. Official way of embedding Google map needs free "Maps Embed API" key though. It is not a secret - it is visible in the url of the map iframe - it is protected by restricting it to given website.

Map is currently using:

  1. open console.cloud.google.com and create (or pick) a project
  2. "APIs & Services" → "Library" → find Maps Embed API → "Enable"
  3. "APIs & Services" → "Credentials" → "Create credentials" → "API key"
  4. edit the key → "Application restrictions" → "Websites" → add addresses of the pages allowed to use it, e.g. https://your-domain.example/*
  5. "API restrictions" → "Restrict key" → select only Maps Embed API
  6. add it to .env as PUBLIC_GOOGLE_MAPS_EMBED_KEY="..." and rebuild / restart the server
